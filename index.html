現金流整理看清每月收入、支出與預備金▾

適合你，如果

  • 薪水入帳沒多久就不見，不知道花去哪
  • 每個月都想存錢，但總是存不下來
  • 卡費、貸款、分期一多，壓力越來越大

我們會一起做

  1. 盤點每月收入，以及固定、變動支出
  2. 整理現有負債、利率與還款順序
  3. 算出你需要的預備金，通常是 3–6 個月生活費
  4. 建立帳戶分流：生活、儲蓄、目標各自分開

你會帶走

  • 一頁看懂的每月現金流表
  • 預備金目標與存到的時間
  • 下個月就能開始的 3 個調整

資產配置依目標與風險，比較不同做法▾

適合你，如果

  • 有一筆存款，不知道該放哪裡
  • 已經在投資，但東買一點西買一點，沒有方向
  • 想開始投資，又擔心自己承受不了波動

我們會一起做

  1. 釐清錢的用途：多久後要用、要用在哪
  2. 了解你能承受的波動與虧損程度
  3. 比較定期定額、單筆、保留現金等做法的優缺點
  4. 檢視現有部位是否過度集中

你會帶走

  • 適合自己的配置比例思考框架
  • 不同做法的比較表與試算
  • 定期檢視、調整的節奏

家庭財務藍圖排出買房、子女、退休的順序▾

適合你，如果

  • 準備成家、結婚，想和另一半對齊財務方向
  • 有了小孩，開始擔心教育金與保障
  • 想買房，或開始思考退休要準備多少

我們會一起做

  1. 列出未來 5–20 年的重大目標與時間點
  2. 估算每個目標大約需要多少錢
  3. 排出優先順序，算出每月要準備的金額
  4. 檢視家庭保障是否有缺口

你會帶走

  • 家庭目標時間軸
  • 每月準備金額試算
  • 先做什麼、後做什麼的優先清單
